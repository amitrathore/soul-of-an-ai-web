# Soul of an AI Website

Static GitHub Pages website for *Soul of an AI / Soul of Anai*.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. In GitHub, open Settings -> Pages.
4. Choose Deploy from a branch, select `main`, and set the folder to `/root`.
5. Save. GitHub will publish the site shortly.

## Structure

- `index.html` — homepage / threshold
- `anai.html` — character profile
- `story.html` — book premise
- `questions.html` — philosophical questions
- `worlds.html` — visual world map
- `creator.html` — creator and creation
- `soul.html` — title meaning and soul framework
- `author.html` — author's reflection
- `gallery.html` — concept art gallery
- `journal.html` — development journal
- `mirror.html` — final reflective page
- `assets/` — CSS, JavaScript, and images
